# PortfolioSite

Персональный сайт-портфолио Unity-разработчика с проектами в VR, AR, MR и интерактивных 3D-приложениях. Сайт помогает быстро познакомиться с работами: открыть описание проекта, посмотреть изображения и видео, перейти к исходному коду и связаться с разработчиком.

## Возможности

- Главный экран с представлением разработчика и специализацией.
- Раздел с избранными работами и каталог остальных проектов.
- Карточки с описанием, технологиями, изображениями и ссылками.
- Просмотр галерей и видео в модальных окнах.
- Навигация по разделам и контакты.

## Техническая реализация

**Стек:** React 19, Vite 7, Tailwind CSS 3, Framer Motion 12, Headless UI, React Icons.

Данные проектов находятся в отдельном JSON-файле. Компоненты карточек, каталога и галерей используют эти данные, поэтому описание, ссылки и набор изображений можно менять независимо от разметки разделов.

| Код | Назначение |
| --- | --- |
| [src/data/projects.json](src/data/projects.json) | Описания, технологии и медиа проектов |
| [src/App.jsx](src/App.jsx) | Состав и порядок разделов страницы |
| [ProjectsShowcase.jsx](src/components/ProjectsShowcase.jsx) | Избранные проекты |
| [CatalogCarousel.jsx](src/components/CatalogCarousel.jsx) | Каталог работ |
| [ShowcaseImageModal.jsx](src/components/ShowcaseImageModal.jsx), [ShowcaseVideoModal.jsx](src/components/ShowcaseVideoModal.jsx) | Просмотр изображений и видео |
| [SmartImage.jsx](src/components/SmartImage.jsx) | Выбор AVIF/WebP, отложенная загрузка и приоритет изображений |
| [src/utils](src/utils) | Общая логика анимаций и модальных окон |
| [vite.config.js](vite.config.js) | Настройки сборки и разделение зависимостей на чанки |

`SmartImage` выбирает доступные варианты изображения через `picture` и `source`. В настройках сборки Framer Motion и Headless UI вынесены в отдельные чанки.
